ПОЛНОЕ ОПИСАНИЕ ПРОЕКТА «ОМА» (hackaton_Oma) — для передачи другой нейронке.

1. ОБЩЕЕ ОПИСАНИЕ

ОМА — мобильное веб-приложение (PWA-стиль, мобильный layout шириной 430px по центру экрана) — маркетплейс строительных материалов и услуг ремонта для белорусской сети магазинов «ОМА». Это MVP для хакатона: фронтенд-приложение без бэкенда, все данные хранятся в localStorage браузера и в статических JSON/JS-файлах.

Стек: React 19, React Router 7, Vite 8, Tailwind CSS 4, Framer Motion (анимации), lucide-react (иконки), TypeScript (только типы, код на JSX), pnpm.

Язык интерфейса: русский. Валюта: белорусский рубль (р.).

2. АРХИТЕКТУРА И НАВИГАЦИЯ

Приложение — SPA с 5 корневыми вкладками в плавающем стеклянном нижнем меню (BottomNav): Главная (/), Мой дом (/my-home), Бригады (/crews), Корзина (/cart), Профиль (/profile). Активная вкладка подсвечивается анимированной «пилюлей». На корзине — красный бейдж с количеством товаров.

Все переходы между экранами анимированы направленными слайдами (Framer Motion, 240 мс): направление определяется глубиной пути или индексом вкладки.

Полный список маршрутов:
- / — главная (каталог)
- /catalog — вкладка «Каталог» внутри главной
- /sections — все разделы
- /category/:id — категория
- /product/:id — карточка товара
- /search — поиск
- /cart — корзина
- /favorites — избранное (вкладка внутри корзины)
- /checkout — оформление заказа
- /order-success — успешный заказ
- /profile — профиль
- /login — вход по телефону
- /orders — мои заказы
- /my-home — ИИ-помощник + проекты ремонта
- /my-home/project/:id — экран проекта
- /crews — маркетплейс бригад
- * — страница 404 с заглушкой

3. ДАННЫЕ (без бэкенда)

3.1 Каталог товаров: src/data/products.json, ~более сотни товаров с полями: id (строковый, напр. «cement-cem-42»), категория cat, подкатегория sub, название, бренд, цена (р.), старая цена oldPrice (для акций), единица измерения (шт/мешок/лист/м²), рейтинг 1–5, число отзывов, emoji вместо фото, артикул sku, остаток stock, описание, характеристики specs (список пар имя-значение), флаг popular. Товары включают: ламинат, OSB, цемент, песок, плитку, клей, смесители, раковины, унитазы, душевые системы, зеркала, кабели, розетки Legrand, выключатели, автоматы, светильники, гипсокартон, шпаклёвку, саморезы, дюбели, уровни, шуруповёрты Makita, перфораторы Bosch, болгарки, наборы инструментов, радиаторы, трубы, насосы, котлы, кровати, комоды, шкафы-купе, шторы, подушки, газонокосилки, триммеры, шланги, капельный полив, мангалы и т.д.

3.2 Категории: src/data/categories.json — 17 категорий (Интерьер/Отделка, Стройматериалы, Инструмент, Сантехника, Электрика, Крепёж, Сад и дача, Мебель, Бытовая техника, Товары для дома, Инженерные системы, Спорт и отдых, Новый год, Автотовары, Электроника, Детям, Красота и здоровье) + служебная категория «Акции». У каждой — иконка (lucide) из src/lib/categoryIcons.js.

3.3 Бригады: src/data/crews.js — список ремонтных бригад по 6 городам Беларуси (Минск, Брест, Витебск, Гомель, Гродно, Могилёв). Одна бригада — собственная «ОМА Сервис» (isOma: true, города Минск/Брест/Гомель/Гродно, рейтинг 4.9, ставка 38 р./м², старт через 1 день, гарантия 3 года), остальные — бригады-партнёры (свой рейтинг, число отзывов, ставка р./м², срок старта, размер команды, лет опыта, гарантия, время отклика, список специализаций, описание, преимущества perks, список отзывов reviewsList). Специализации бригад совпадают по id со сценариями ИИ (floors, bath, electric, walls, heating, furniture, garden).

3.4 Промокоды: src/lib/promo.js — OMA10 = 10%, «ХАЛЯВА5» = 5%.

3.5 Хранилище состояния: React Context (StoreContext) + localStorage. Ключи: oma.cart (корзина: {id: qty}), oma.favorites, oma.orders, oma.user, oma.promo, oma.projects, oma.city (город по умолчанию «Минск»).

4. ФУНКЦИИ ПО ЭКРАНАМ

4.1 Главная (/ и /catalog)
- Шапка: логотип «ОМА», выбор города (CityPicker — нижняя шторка со списком 6 городов, сохраняется в стейте).
- Прилипающий блок: строка поиска (SearchBar — ведёт на /search) + вкладки «Главная»/«Каталог» с анимированным индикатором.
- Лента категорий: горизонтальный скролл круглых иконок (первая — красная «Акции»), тап — переход в категорию.
- На «Главной»: свайпаемая лента промо-баннеров (3 градиентных баннера: «Скидки до 60%», «Всё для дома», «Электроинструмент») с точками-индикаторами; сетка 2 колонки «Популярные товары» (8 товаров); горизонтальная лента «Акции» (товары со скидкой, цена перечёркнута, красный ценник); футер.
- На «Каталоге»: сетка карточек категорий 2 колонки.

4.2 Категория (/category/:id)
- Список подкатегорий-фильтров (горизонтальные чипы), сортировка (популярность/цена), сетка товаров 2 колонки. Для id=«akcii» — все товары со скидкой.

4.3 Карточка товара (/product/:id)
- Emoji-превью, название, бренд, рейтинг со звёздами (Stars), число отзывов, цена и перечёркнутая старая цена, единица измерения, артикул, остаток на складе.
- Описание, таблица характеристик specs.
- Счётчик количества, кнопки «В корзину» и «В избранное» (сердечко, тост-уведомление).
- Горизонтальная лента «Похожие товары» (из той же категории).

4.4 Поиск (/search)
- Живой поиск по названию/бренду/категории, результаты сеткой; пустое состояние.

4.5 Корзина и избранное (/cart, /favorites)
- Один экран с сегмент-переключателем «Корзина / Избранное» и счётчиками.
- Корзина: список позиций с emoji, ценой за единицу, счётчиками +/−, удалением; промокод (OMA10, ХАЛЯВА5) с расчётом скидки; итог; кнопка «Оформить заказ» → /checkout; пустое состояние с CTA в каталог.
- Избранное: карточки отложенных товаров, удаление из избранного.

4.6 Оформление заказа (/checkout)
- Форма получателя: имя, телефон (подставляются из профиля).
- Способ получения: «Самовывоз из магазина» (г. Минск, ул. Притыцкого, 62, бесплатно) или «Доставка» (тогда обязательный адрес).
- Способ оплаты: картой онлайн / при получении.
- Кнопка автозаполнения демо-данными (демо-пользователь Дмитрий Ковалёв).
- Валидация через тосты. При отправке: placeOrder создаёт заказ (6-значный номер, дата, позиции, сумма, статус «В обработке», доставка, адрес, оплата), очищает корзину, редирект на /order-success (галочка, номер заказа, кнопки «К заказам» / «На главную»).

4.7 Профиль (/profile)
- Если не авторизован: карточка «Войдите в аккаунт» → /login.
- Если авторизован: аватар, имя, телефон; меню: Мои заказы (/orders — список заказов с номером, датой, статусом, суммой и составом), Адрес доставки, Способы оплаты, Помощь, О приложении; кнопка «Выйти» (тост).
- Ссылка на профиль есть и в шапке «Мой дом» (круглый аватар).

4.8 Вход (/login)
- Имитация авторизации как в приложении ОМА: поле телефона с флагом Беларуси +375 (SVG-флаг), кнопка «Войти» (неактивна, пока < 9 цифр) → шаг кода из 4 цифр (любой) → вход. Отдельная кнопка «Быстрый вход» (молния) — мгновенный вход демо-пользователем Дмитрием Ковалёвым (+375 29 123-45-67, Минск, пр. Независимости 58) для защиты/демо.

5. КЛЮЧЕВАЯ ФИШКА №1 — ИИ-ПОМОЩНИК «МОЙ ДОМ» (/my-home)

5.1 Блок ИИ-помощника (верх экрана, синий mesh-градиент с анимированными блобами):
- Приветствие по имени пользователя («Здравствуйте, Дмитрий 👋», если вошёл).
- Текстовое поле «Что нужно сделать?» с предзаполненным примером задачи и кнопкой «Подобрать с ИИ» (Ctrl/Cmd+Enter тоже запускает).
- Чипы «Популярное»: 8 быстрых сценариев (Стяжка и полы, Ванная, Электрика, Стены, Отопление, Мебель, Сад, Инструмент) — тап подставляет готовый текст задачи.
- После отправки ИИ задаёт уточняющий вопрос: «Делаем из этого проект ремонта или просто закупаем материалы?» — две кнопки: «Проект ремонта» (смета, этапы, бригада) и «Только закупка» (подбор в корзину).
- Затем анимированный лоадер с пошаговой сменой фраз («Анализирую задачу…», «Подбираю материалы из каталога ОМА (N)…», «Планирую этапы работ и смету…» / «Считаю количество…»), ~2 секунды.

5.2 Логика анализа задачи (src/lib/ai.js, детерминированный «ИИ» на правилах):
- Распознавание сценария по ключевым словам (score = число совпавших ключей, лучший побеждает). 8 сценариев: floors (стяжк/пол/ламинат/цемент…), bath (ванн/плитк/смесит…, база 6 м²), electric (электр/розетк/кабел…), walls (стен/гипсокартон/шпакл…), heating (отоплен/батаре/котёл…), furniture (мебел/кроват/шкаф…), garden (сад/газон/полив…), repair (инструмент/дрел/перфорат…). Если ничего не распознано — сценарий «Стяжка и полы» и пометка «(по умолчанию)».
- Извлечение площади из текста регуляркой: «20 м²», «20м2», «20 кв.м», «20 квадратов» — clamp 1–500, по умолчанию база сценария (20 м², для ванной 6 м²).
- Генерация 3 комплектов: «Минимальный» (только необходимое), «Стандарт» (бейдж «Популярный», материалы + инструмент), «Профессиональный» (запас + профи-инструмент). Каждая позиция комплекта: товар каталога + количество; позиции с флагом perArea масштабируются пропорционально площади (qty = ceil(base_qty × area/base)), остальные фиксированные.

5.3 Шторка результата «Подборка ОМА» (AIResultSheet, нижний шит с drag-to-close):
- Заголовок «Проект ремонта» или «Закупка материалов», текст задачи, чипы «что понял ИИ»: сценарий (или «по умолчанию») и площадь.
- Для проекта — тумблер «Своими силами / С бригадой ОМА».
- 3 карточки комплектов с радиовыбором; выбранный раскрывается — список позиций с чекбоксами (можно исключать позиции), emoji, названием, брендом, ценой за единицу, количеством и суммой по позиции; у каждого комплекта показаны количество позиций и итог.
- При «С бригадой ОМА»: список бригад города (ОМА Сервис первой, затем 2–3 партнёра под специализацию сценария) с рейтингом, ставкой р./м² и стоимостью работ = ставка × площадь; выбор одной.
- Липкий низ: строка «Товары X + работа Y», итог, кнопка «Всё в корзину» / «Создать проект» / «Создать проект с бригадой».
- Действия: «Только закупка» — все отмеченные товары добавляются в корзину и редирект в корзину; «Проект» — создаётся проект.

6. КЛЮЧЕВАЯ ФИШКА №2 — ПРОЕКТЫ РЕМОНТА

6.1 Список проектов (низ /my-home, «Мои проекты»):
- Карточка проекта: иконка молотка (жёлтая — ожидает, синяя — в работе), название (текст задачи), бейдж статуса «Ожидает»/«В работе», строка бригады (имя + площадь или «Без бригады • материалы ОМА»), состав («N поз. • материалы X • работа Y»), итоговая сумма.
- У проекта без бригады — кнопка «Выбрать бригаду для проекта» (ведёт на /crews?project=<id>).
- У ожидающего — кнопка «Оформить и начать работу» (pending → active).
- У активного — строка «Этап N из 4 • открыть проект».
- Пустое состояние: «Проектов пока нет» с подсказкой.

6.2 Экран проекта (/my-home/project/:id):
- Синий hero-градиент: кнопка «назад», название проекта, бейджи статуса («Ожидает подтверждения» / «В работе» / «Финальный этап») и бригады (имя + ставка р./м²).
- Карточка бригады: аватар (каска для ОМА / первая буква), подпись «Официальная бригада ОМА» / «Бригада-партнёр ОМА», рейтинг, ставка и площадь; кнопка «Сменить» (пока проект не подтверждён). Если бригады нет — пунктирная карточка-приглашение выбрать бригаду.
- Таймлайн «Этапы работ» — 4 фиксированных этапа: 1) Замер и подтверждение сметы, 2) Доставка материалов с подъёмом, 3) Черновые работы, 4) Чистовые работы и приёмка. У каждого — подпись-подсказка (например «Бригада свяжется и зафиксирует смету на объекте»). Визуальные состояния: пройден (синяя галочка), текущий (пульсирующая точка + бейдж «в работе»), будущий (серый). Соединительная линия закрашивается по мере прохождения.
- Список материалов ОМА (первые 5 позиций с emoji, названием, количеством и суммой, «…и ещё N поз.»), разбивка: материалы + работа бригады, строка «Итого».
- Баннер гарантии: «Гарантия на работы — 2 года. Чат с бригадой доступен 24/7».
- Кнопки: иконка чата (тост-заглушка) и главная CTA: «Оформить и начать работу» (для pending) → статус active; «Подтвердить этап» (для active) → переключает на следующий этап с тостом; на финальном этапе — «Проект на приёмке» (disabled).
- Если проект не найден — EmptyState с кнопкой «Мой дом».

7. КЛЮЧЕВАЯ ФИШКА №3 — МАРКЕТПЛЕЙС БРИГАД (/crews)

- Синяя шапка с градиентом: заголовок «Бригады», выбор города (стеклянная кнопка с MapPin), слоган «Проверенные мастера на маркетплейсе ОМА. Оплата через ОМА — только после приёмки этапа».
- Если открыт с ?project=<id>: карточка «Подбираем бригаду для проекта …» с кнопкой сброса. Если проектов нет вообще — карточка «Чтобы выбрать бригаду, нужен проект» с CTA «Создать проект» → /my-home.
- Фильтр по специализации (горизонтальные чипы: Все работы, Полы и стяжка, Ванная, Электрика, Стены, Отопление, Мебель, Участок) с анимированной «пилюлей».
- Блок бригады ОМА: «ОМА Сервис» всегда первая и выделена (синяя рамка, каска, рейтинг 4.9, 1240 отзывов, 38 р./м², старт через 1 день). Если в городе нет бригады ОМА (Витебск, Могилёв) — оранжевое уведомление с перечислением городов присутствия.
- Секция «Партнёры ОМА • N»: сортировки (рекомендуем/рейтинг/цена/скорость старта), карточки партнёров с анимированным появлением; у каждой: буква-аватар, имя, рейтинг + отзывы, первая специализация (подсвечивается активным фильтром), ставка, срок старта, число выполненных объектов, лет опыта, размер команды, гарантия.
- Тап по бригаде — нижняя шторка CrewSheet: полное описание, все специализации, метрики (объектов, лет, мастеров, гарантия, отклик), преимущества perks, список отзывов; кнопка «Выбрать бригаду» (если открыт для проекта — привязывает бригаду к проекту: crewTotal = ставка × площадь; иначе тост-заглушка).
- Пустое состояние фильтра: «Партнёров с такой специализацией в городе пока нет» + кнопка «Показать все работы».
- Блок «Вы бригада? Станьте продавцом ОМА» (модель как продавцы на Ozon/WB): заказы из проектов покупателей, материалы уже куплены, выплаты после приёмки этапа; кнопка «Оставить заявку» (тост-заглушка).

8. UI/ДИЗАЙН-СИСТЕМА

- Мобильный layout: колонка max-w-430px по центру, тень, минимальная высота 100dvh.
- Фирменный синий бренд-цвет (brand-600 ≈ #1d5dbe), тёмно-синий текст (navy), красный акцент для цен/скидок (accent), светлый фон (bg), скруглённые карточки (rounded-2xl/3xl), мягкие тени (shadow-soft/lift/glass).
- Нижняя навигация — «стекло» (backdrop-blur) с пилюлей активной вкладки (layoutId-анимация).
- Анимации: направленные слайды страниц, stagger-появление списков, spring-тапы (scale 0.9–0.96), layout-анимации пилюль и сегмент-тумблеров, анимированные mesh-блобы на градиентах, пульсирующая точка текущего этапа, шторки с drag-to-close (порог 110px).
- Тост-уведомления (Toast) сверху контейнера для всех действий (добавление в корзину/избранное, промокод, заказ, бригада, этап, заявки).
- Пустые состояния (EmptyState) с иконкой, заголовком и CTA-кнопкой.
- Формат цены: белорусские рубли с двумя знаками, «р.» (функция rub в src/lib/format.js).
- Эмодзи используются вместо фотографий товаров.

9. ТЕХНИЧЕСКИЕ ДЕТАЛИ

- Весь стейт в одном StoreProvider: cart (объект id→qty), favorites (массив id), orders, user, promo, projects, city; всё автосохраняется в localStorage при каждом изменении и восстанавливается при загрузке.
- API стора: addToCart, setQty, removeFromCart, clearCart, toggleFav, login(phone), demoLogin, logout, applyPromo(code), placeOrder(info), createProject({title, items, crew, area, scenario}), createProjectFromCart, assignCrew(projectId, crew, area), approveProject(id), advanceStage(id), setCity, showToast.
- Модель проекта: { id: 'p'+timestamp, title, items: [{id, qty}], itemsTotal, crew, crewTotal = crew.rate × area, area, scenario, status: 'pending'|'active', currentStage: 0..3 }.
- ИИ — детерминированный: никаких сетевых вызовов и внешних API; «интеллект» = ключевые слова + регэксп площади + шаблонные комплекты. Это осознанно для оффлайн-демо.
- Сборка: pnpm dev (Vite, порт 5173), pnpm build, pnpm lint (oxlint).
