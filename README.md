# ОМА — всё для дома и ремонта (хакатон)

Мобильный веб-клиент ОМА с ИИ-помощником по ремонту.

Проект собран из двух репозиториев:

- **[hackaton_Oma](https://github.com/tsimurik/hackaton_Oma)** — основа и функционал: каталог, категории, поиск, карточка товара, корзина с промокодами, оформление заказа, заказы, избранное, вход, профиль.

## Навигация

Нижнее меню: **Главная · Мой дом · Бригады · Корзина · Профиль**.

- **Главная** — вверху лента категорий; внутри две вкладки: «Главная» (баннеры, популярное, акции) и «Каталог» (все разделы).
- **Корзина** — внутри вкладки «Корзина» и «Избранное». Из корзины можно сделать проект ремонта.
- **Профиль** — «⚡ Быстрый вход для демо»: готовый пользователь без SMS и полей. Имя, телефон и адрес сами подставляются в оформление заказа; там же есть «Заполнить за меня».
- **[oma-ozon](https://github.com/dimasahnovic21-ai/oma-ozon)** — дизайн и анимации: тени и mesh-градиенты, стеклянное нижнее меню с «пилюлей», направленные слайды между экранами, press-анимации, stagger-появление, ИИ-подборка.

## Запуск

```bash
npm install
npm run dev
```

Открыть адрес из терминала (обычно http://localhost:5173) и включить мобильный режим в DevTools (ширина ~390 px).

Сборка для деплоя: `npm run build`, результат в `dist/`. Для Vercel/Netlify включите SPA-фолбэк на `index.html` (маршруты на react-router).

## «Мой дом» — ИИ-помощник

Вкладка «Мой дом» начинается со скрипта вкладки «Главное» из oma-ozon:

1. Пользователь описывает задачу своими словами («Положить плитку в ванной 8 м²») или жмёт быстрый сценарий.
2. ИИ уточняет: **проект ремонта** (смета, этапы, бригада) или **только закупка** (материалы в корзину).
3. Лоадер показывает шаги анализа.
4. ИИ (`src/lib/ai.js`) распознаёт сценарий по ключевым словам, вытаскивает площадь и собирает 3 комплекта из реального каталога `products.json`: Минимальный / Стандарт / Профессиональный. Количество материалов масштабируется по площади.
5. В шторке можно снять ненужные позиции. Закупка → «Всё в корзину». Проект → своими силами или с бригадой ОМА, проект появляется в «Моих проектах».
6. Проект проходит 4 этапа (замер → доставка → черновые → чистовые) на экране `/my-home/project/:id`.

Сценарии: стяжка и полы, ванная, электрика, стены, отопление, мебель, сад, инструмент.

## «Бригады» — маркетплейс бригад

Бригады регистрируются на ОМА как продавцы услуг, по модели продавцов на Ozon / Wildberries: свой рейтинг, отзывы, цена за м², специализации и города работы.

- **Бригада ОМА в вашем городе — всегда первая и выделена.** Если в городе её нет (например, Витебск, Могилёв), показывается подсказка, где она работает.
- Город выбирается в шапке «Бригад» или «Главной» и запоминается.
- Фильтр по видам работ и сортировка партнёров: рекомендуем (рейтинг с учётом числа отзывов), дешевле, по рейтингу, быстрее старт.
- **Выбрать бригаду можно только для проекта из «Моего дома».** Без проекта карточка бригады ведёт создать проект. В проекте без бригады есть кнопка «Выбрать бригаду» — она открывает «Бригады», отфильтрованные под задачу проекта.
- Цена работ = ставка бригады × площадь. Площадь можно поправить при выборе.
- Блок «Станьте продавцом ОМА» — вход для новых бригад.

Данные бригад: `src/data/crews.js`.

## Структура

```
src/
  components/AIAssistant.jsx    ИИ-ввод задачи (скрипт «Главное» из oma-ozon)
  components/AIResultSheet.jsx  шторка «Подборка ОМА»: комплекты, бригады, итог
  components/BottomNav.jsx      стеклянное меню с анимированной пилюлей
  lib/ai.js                     распознавание задачи и сборка комплектов
  pages/Home.jsx                лента категорий, вкладки Главная / Каталог
  pages/MyHomePage.jsx          ИИ + мои проекты
  pages/CartPage.jsx            корзина и избранное
  pages/ProjectPage.jsx         этапы проекта, выбранная бригада
  pages/CrewsPage.jsx           маркетплейс бригад
  components/CrewSheet.jsx      карточка бригады и выбор для проекта
  data/crews.js                 бригады, города, сортировки
  store/StoreContext.jsx        корзина, избранное, заказы, проекты (localStorage)
```
